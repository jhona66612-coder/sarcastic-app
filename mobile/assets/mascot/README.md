# SlothBot

Original image generated with the built-in image generation tool for this project.
Asset: `slothbot-sprites.png`, a transparent three-frame horizontal sheet.

Frames, left to right: idle, blink, speaking. React Native clips each third; no runtime image generation or external asset URL is required.

Prompt: Three equal square cells showing the same adorable seated baby sloth, soft 3D clay style, taupe fur, cream face, dark plum hoodie and a lime check accent. Identical proportions and camera across frames. First frame eyes open and mouth closed, second blinking, third eyes open and mouth slightly open as if speaking. Transparent background, no text or border.

Animation and reduced-motion behavior are implemented in `src/ui/SlothMascot.tsx`.
